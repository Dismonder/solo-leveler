# Solo Leveler

Offline-first fitness RPG w klimacie Systemu: onboarding, progres postaci, mini-gry, loot i avatary rang działają lokalnie oraz bez kluczy API.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
